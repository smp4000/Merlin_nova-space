# Modul-Prompts

Die Texte sind konsolidierte, eigenständig nutzbare Arbeitsaufträge aus der Planung.
Sie sind keine wörtlichen vollständigen Chat-Transkripte. Noch keine Implementierungsfreigabe.

| Reihenfolge | Datei | Inhalt |
|---|---|---|
| 01 | [Landing](01-landing.md) | Neu aus der freigegebenen Planung konsolidiertes Landing-Briefing. |
| 02 | [Partnerregistrierung](02-partnerregistrierung.md) | Bisheriger Modulauftrag mit SEPA und offenen Entscheidungen. |
| 03 | [Partner-Dashboard](03-partner-dashboard.md) | Erster Einstieg und Übergang zur Arbeitsübersicht. |
| 04 | [Team & Zugänge](04-team-und-zugaenge.md) | Neue detaillierte Planung, Rollen und Einladungen. |
| 05 | [Stationsverwaltung](05-stationsverwaltung.md) | Stammdaten, Öffnungszeiten, Zuständigkeiten, Pause/Archiv und Systemgrenzen. |
| 06 | [Mitarbeiter & Mitarbeitereinladung](06-mitarbeiter-und-einladung.md) | DATEV-orientierte Felder, Selbsterfassung, Prüfung und Personal-/Lohnrechte. |
| 07 | [Schichtplanung](07-schichtplanung.md) | Vorlagen, Zeit-/Regelmodell, Veröffentlichung und eigene Mitarbeiteransicht. |
| 08 | [Abwesenheiten](08-abwesenheiten.md) | Urlaubskonto, Antrag/Freigabe, Krankmeldung/Nachweis, Wunschfrei und Planwirkung. |
| 09 | [Interaktives Dashboard](09-dashboard-interaktiv.md) | Begrenzter Mockup-Auftrag mit lokalen Interaktionen, kein Backendmodul. |
| 10 | [Super-Admin: Landing & Preise](10-super-admin-landing-und-preise.md) | CMS, Modulkatalog, Preisversionen, Veröffentlichung und Vertragsgrenzen. |
| Bilder | [Bildbriefings](BILD-PROMPTS.md) | Rekonstruierte Briefings aller generierten Mockups. |

Vor späterer Programmierung jeweiligen Prompt ausdrücklich auf Umsetzung umstellen,
offene Punkte prüfen und mit den tatsächlichen Projektdateien abgleichen.
Konkreter späterer Startprompt und Abhängigkeitsreihenfolge:
[Umsetzungsübergabe](../leitfaeden/UMSETZUNGSUEBERGABE.md).
