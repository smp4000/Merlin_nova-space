## Modellierungsgrundsätze der aktuellen Spezifikation

Stationenanzahl ist kein Kriterium für Rechtsform. Einzelunternehmer kann 100 Stationen haben;
GmbH kann eine Station haben. Geschäftlicher rechtlicher Name statt pauschal „Registername“.
Organisation ≠ Vertragspartner ≠ Benutzer ≠ Personalakte ≠ Station ≠ Rechnungsprofil ≠ Zahlungsprofil.
Mandat ≠ Aboabschluss. Einladungsversand ≠ angenommener Zugang.
Diese Grundsätze präzisieren die Planung und sind keine Aussage über bereits implementierte Systeme.
