# Merlin Nova – lokale technische Basis

Laravel-/Filament-Grundgerüst ohne Fachmodule. Einrichtung, Versionen, lokale
Zugangsdatenverwaltung und Prüfungen: [Lokale Entwicklung](../docs/leitfaeden/LOKALE-ENTWICKLUNG.md).

Start im Ordner `application/`: `docker compose up -d --wait`.
Nur nach Erstinstallation gemäß Leitfaden; PHP und Composer laufen im Container,
Node 24 LTS/npm und Python 3 auf dem Entwicklungshost. Standard-Laravel-Willkommensseite
und technisches Adminpanel, keine implementierte Landingpage oder Registrierung.
